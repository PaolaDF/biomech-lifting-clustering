# Biomechanical clustering of lightweight lifting strategies and associated balance demands

This repository contains the Python code developed for the biomechanical analysis and clustering of lifting strategies. This work is part of the manuscript submitted to **Gait & Posture**.

## 📧 Contact
For any questions regarding the code or dataset, please contact: paola.diflorio@unibo.it

---

## 📂 Repository Structure

- `preprocessing.py`: Cleans raw biomechanical data and prepares files.
- `utils.py`: Library containing core functions for biomechanical metrics and strategies clustering.
- `main_analysis.py`: Main script to run the clustering model and generate results/figures.
